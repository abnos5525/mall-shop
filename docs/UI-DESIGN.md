# UI direction

- Product: DropClub.
- Style: premium editorial commerce, minimal and trustworthy; not a generic admin template.
- Default: Persian language, `dir="rtl"`, mobile-first.
- Palette: warm neutral background, deep ink/navy text, restrained lime/emerald accent, muted borders. Keep contrast accessible.
- Layout: compact top bar, search/discovery, offer cards with clear price/source, bottom navigation safe-area aware.
- Typography: readable Persian font with reliable fallback; use local/system or properly licensed font. Avoid loading external fonts as a hard dependency.
- Motion: subtle and purposeful; respect reduced-motion.
- Telegram: use theme params when available, handle safe-area/content-safe-area, viewport changes and browser fallback.
- States: skeleton, empty, error, retry, success, disabled, expired offer.
- Never use fake scarcity, fake discount percentages, fake reviews, or misleading "verified" badges.
- Affiliate and sponsored labels must be visible near the CTA.
